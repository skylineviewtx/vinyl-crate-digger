# Security Policy

## Supported versions

Vinyl Crate Digger is maintained by one person, so security fixes go into the latest release only. If you're on an older version, please update before reporting.

| Version | Supported |
| ------- | --------- |
| 2.4.x (latest) | ✅ |
| Older than 2.4 | ❌ |

## Reporting a vulnerability

**Please don't report security problems in public Issues or Discussions.** Report them privately instead:

- **Preferred:** use the **Report a vulnerability** button on this repo's [Security tab](../../security).
- **Or email:** clayton@claytonjkucera.com with "Security" in the subject line.

Please include:

- What the problem is and what someone could do with it
- Steps to reproduce it
- The app version you tested (shown in Windows' Installed
